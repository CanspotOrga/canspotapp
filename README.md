# CanSpot

Prototyp einer mobilen Preisvergleichs-App für Energy Drinks (Web-App und iOS über Capacitor).

- `index.html`: die komplette Web-App. Sie lädt alle Daten live aus Supabase.
- `www/` und `ios/`: Capacitor-Kopie und iOS-Projekt.
- `supabase/`: Datenbankschema und aktueller Datenstand als SQL und CSV, siehe [supabase/README.md](supabase/README.md).
- [DATENQUELLEN.md](DATENQUELLEN.md): verbindliche Regeln, welche Daten verwendet werden dürfen.

CanSpot ist nicht mit den genannten Händlern oder Herstellern verbunden.
